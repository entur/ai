Entur AI is a Claude Code plugin marketplace. Install via the marketplace command, then enable individual plugins.

## Add the marketplace

<CopyCommand client:load>/plugin marketplace add entur/ai</CopyCommand>

## Install a plugin

<CopyCommand client:load>/plugin install bootstrap@entur</CopyCommand>
<CopyCommand client:load>/plugin install scr@entur</CopyCommand>
<CopyCommand client:load>/plugin install cicd-workflows@entur</CopyCommand>

## Use a skill

Skills auto-trigger from natural language. To bootstrap a new app, ask the agent to "scaffold a new Entur service".
See the [Skills](/skills) index for all available skills.
